# M0 — Auth + RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build M0 (Auth + RBAC) of the Aquazaku system: identity, authorization with 4-role matrix + scope model, audit log consultable from UI, BFF pattern, and seed for the first admin.

**Architecture:** Polyrepo with two independent projects — `api/` (Fastify + Drizzle + Postgres + Better-Auth + custom authz module) and `web/` (Next.js App Router BFF). Web never talks directly to api from the browser; all communication goes through `apiServerFetch()` helper server-to-server. Permission matrix is declared in TypeScript, applied in ONE data layer (`scopedQuery`). Audit log is append-only (REVOKE + trigger). All defense-in-depth: skill + helper module + ESLint rule.

**Tech Stack:**
- Runtime: Node.js 20 LTS
- api/: Fastify 4.x, Drizzle, Postgres 16, Better-Auth 1.3.x, Zod, argon2id, Pino, Resend (prod) / MailHog (dev), Vitest + Supertest
- web/: Next.js 15 (App Router), React 19, Tailwind, TanStack Table, Vitest + Testing Library + MSW
- Tests: Vitest with min coverage `authz/` ≥85%, global ≥70%

**Spec:** `/docs/superpowers/specs/2026-08-19-auth-rbac-design.md`
**ADRs:** `/docs/decisiones/0001-stack-m0.md`, `/docs/decisiones/0002-bff-pattern.md`, `/docs/decisiones/0003-roles-permisos-matriz.md`

## Global Constraints

- TypeScript strict mode in both `api/` and `web/`
- All files use 2-space indentation, single quotes, no semicolons (project convention)
- No `Co-Authored-By` in commits (per project AGENTS.md)
- Conventional commits: `feat:`, `fix:`, `chore:`, `test:`, `docs:`
- Every commit must leave the project in a green state (tests + lint + typecheck pass)
- No TODO/PLACEHOLDER comments in shipped code
- All API endpoints require authentication except `/auth/sign-in`, `/auth/forgot-password`, `/auth/reset-password`
- Cookie name: `aquazaku_session`, httpOnly, sameSite=Lax, 7-day expiry with sliding window
- Password hashing: argon2id via Better-Auth, min length 8
- Rate limit: 5 failed login attempts per IP+email per 15 minutes
- Drizzle migrations are explicit SQL, never auto-generated against production
- `audit_log` is append-only: REVOKE UPDATE, DELETE + trigger that rejects mutations
- ESLint rule in web/: bans `fetch()` direct and `localStorage`
- No JWT — sessions live in DB for revocation

```ts
import { pgTable, uuid, text, timestamp, boolean, jsonb, inet, bigserial, pgEnum, primaryKey, index } from 'drizzle-orm/pg-core'

export const userStatusEnum = pgEnum('user_status', ['active', 'inactive'])
export const auditResultEnum = pgEnum('audit_result', ['ok', 'denied'])

export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  email: text('email').notNull().unique(),
  passwordHash: text('password_hash').notNull(),
  name: text('name').notNull(),
  status: userStatusEnum('status').notNull().default('active'),
  mustChangePassword: boolean('must_change_password').notNull().default(true),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
})

export const sessions = pgTable('sessions', {
  id: text('id').primaryKey(),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  roles: text('roles').array().notNull(),
  expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
  ip: inet('ip'),
  userAgent: text('user_agent'),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (t) => ({
  userIdx: index('sessions_user_idx').on(t.userId),
}))

export const roles = pgTable('roles', {
  name: text('name').primaryKey(),
  description: text('description').notNull(),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
})

export const userRoles = pgTable('user_roles', {
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  roleName: text('role_name').notNull().references(() => roles.name),
  grantedAt: timestamp('granted_at', { withTimezone: true }).notNull().defaultNow(),
  grantedBy: uuid('granted_by').references(() => users.id),
}, (t) => ({
  pk: primaryKey({ columns: [t.userId, t.roleName] }),
}))

export const auditLog = pgTable('audit_log', {
  id: bigserial('id', { mode: 'number' }).primaryKey(),
  userId: uuid('user_id'),
  rolEjercido: text('rol_ejercido').array(),
  action: text('action').notNull(),
  resource: text('resource'),
  resourceId: text('resource_id'),
  result: auditResultEnum('result').notNull(),
  requestId: uuid('request_id'),
  ip: inet('ip'),
  userAgent: text('user_agent'),
  payload: jsonb('payload'),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (t) => ({
  userIdx: index('audit_user_idx').on(t.userId),
  createdIdx: index('audit_created_idx').on(t.createdAt),
  actionIdx: index('audit_action_idx').on(t.action),
}))
```

- [ ] **Step 6: Add audit_log triggers to migration**

Append to `src/db/migrations/0000_*.sql`:

```sql
-- audit_log append-only enforcement
CREATE OR REPLACE FUNCTION reject_audit_mutation()
RETURNS trigger AS $$
BEGIN
  RAISE EXCEPTION 'audit_log is append-only';
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER no_update_audit BEFORE UPDATE ON audit_log
  FOR EACH ROW EXECUTE FUNCTION reject_audit_mutation();
CREATE TRIGGER no_delete_audit BEFORE DELETE ON audit_log
  FOR EACH ROW EXECUTE FUNCTION reject_audit_mutation();

REVOKE UPDATE, DELETE ON audit_log FROM aquazaku_app;
```

```ts
import { eq } from 'drizzle-orm'
import type { SQL, SelectQueryBuilder } from 'drizzle-orm'
import { PERMISSION_MATRIX, type Action, type Resource, type Role } from './matrix'
import type { UserContext } from './can'

export function applicableScopes(
  user: UserContext,
  resource: Resource,
  action: Action,
): string[] {
  const scopes = new Set<string>()
  for (const role of user.roles) {
    for (const rule of PERMISSION_MATRIX[role]) {
      if (rule.resource === resource && rule.action === action) {
        scopes.add(rule.scope)
      }
    }
  }
  return Array.from(scopes)
}

export function scopedQuery<T extends SelectQueryBuilder<any, any, any>>(
  user: UserContext,
  baseQuery: T,
  resource: Resource,
  action: Action,
): T {
  const scopes = applicableScopes(user, resource, action)

  // 'todo' wins: no filter
  if (scopes.includes('todo')) return baseQuery

  let query = baseQuery
  for (const scope of scopes) {
    if (scope === 'propio') {
      // Assumes the table has a `createdBy` column
      query = query.where(eq((query as any)._.table.createdBy, user.id)) as T
    }
    // Other scopes are placeholders for M1+ modules
  }
  return query
}
```

```ts
import type { FastifyReply, FastifyRequest } from 'fastify'
import { eq } from 'drizzle-orm'
import { db } from '@/db/client'
import { sessions, users } from '@/db/schema'
import { can, type UserContext } from './can'
import { emit } from './audit'
import type { Action, Resource, Role } from './matrix'

declare module 'fastify' {
  interface FastifyRequest {
    user?: UserContext
  }
}

export async function requireAuth(
  req: FastifyRequest,
  reply: FastifyReply,
): Promise<void> {
  const sessionId = req.cookies['aquazaku_session']
  if (!sessionId) {
    return reply.code(401).send({ code: 'UNAUTHENTICATED' })
  }

  const [session] = await db
    .select()
    .from(sessions)
    .where(eq(sessions.id, sessionId))
    .limit(1)

  if (!session || session.expiresAt < new Date()) {
    return reply.code(401).send({ code: 'SESSION_EXPIRED' })
  }

  const [user] = await db
    .select()
    .from(users)
    .where(eq(users.id, session.userId))
    .limit(1)

  if (!user || user.status !== 'active') {
    return reply.code(401).send({ code: 'USER_INACTIVE' })
  }

  req.user = {
    id: user.id,
    roles: session.roles as Role[],
  }
}

export function requirePermission(resource: Resource, action: Action) {
  return async (req: FastifyRequest, reply: FastifyReply): Promise<void> => {
    if (!req.user) {
      return reply.code(401).send({ code: 'UNAUTHENTICATED' })
    }

    const allowed = can(req.user, resource, action)
    const requestId = (req.headers['x-request-id'] as string) ?? crypto.randomUUID()

    if (!allowed) {
      await emit({
        userId: req.user.id,
        rolEjercido: req.user.roles,
        action: 'PERMISSION_DENIED',
        resource,
        resourceId: undefined,
        result: 'denied',
        requestId,
        ip: req.ip,
        userAgent: req.headers['user-agent'],
        payload: { attempted_action: action },
      })
      return reply.code(403).send({ code: 'FORBIDDEN', resource, action })
    }

    await emit({
      userId: req.user.id,
      rolEjercido: req.user.roles,
      action: 'PERMISSION_GRANTED',
      resource,
      resourceId: undefined,
      result: 'ok',
      requestId,
      ip: req.ip,
      userAgent: req.headers['user-agent'],
      payload: { attempted_action: action },
    })
  }
}
```

```ts
import type { FastifyInstance } from 'fastify'
import { requireAuth } from '@/modules/authz/middleware'
import { emit } from '@/modules/authz/audit'

export async function authRoutes(app: FastifyInstance): Promise<void> {
  // GET /auth/me — returns current user with roles
  app.get('/auth/me', { preHandler: requireAuth }, async (req) => {
    return {
      id: req.user!.id,
      roles: req.user!.roles,
    }
  })

  // POST /auth/sign-out — invalidates session
  app.post('/auth/sign-out', { preHandler: requireAuth }, async (req, reply) => {
    const sessionId = req.cookies['aquazaku_session']
    if (sessionId) {
      await req.server.pg.query('DELETE FROM sessions WHERE id = $1', [sessionId])
    }
    reply.clearCookie('aquazaku_session', { path: '/' })
    await emit({
      userId: req.user!.id,
      rolEjercido: req.user!.roles,
      action: 'LOGOUT',
      result: 'ok',
      requestId: (req.headers['x-request-id'] as string) ?? crypto.randomUUID(),
      ip: req.ip,
      userAgent: req.headers['user-agent'],
    })
    return { ok: true }
  })
}
```

```ts
const attempts = new Map<string, { count: number; resetAt: Date }>()

export function checkRateLimit(key: string, max = 5, windowMs = 15 * 60 * 1000): void {
  const now = Date.now()
  const record = attempts.get(key)
  if (!record || record.resetAt < new Date(now)) {
    attempts.set(key, { count: 1, resetAt: new Date(now + windowMs) })
    return
  }
  if (record.count >= max) {
    throw new Error('RATE_LIMITED')
  }
  record.count++
}

export function recordFailedAttempt(key: string, max = 5, windowMs = 15 * 60 * 1000): void {
  const now = Date.now()
  const record = attempts.get(key)
  if (!record || record.resetAt < new Date(now)) {
    attempts.set(key, { count: 1, resetAt: new Date(now + windowMs) })
    return
  }
  record.count++
}

export function clearAttempts(key: string): void {
  attempts.delete(key)
}
```

```ts
import { randomBytes } from 'crypto'
import { eq, and, isNull, gt } from 'drizzle-orm'
import { db } from '@/db/client'
import { users, passwordResets } from '@/db/schema'
import { hash as argonHash } from '@node-rs/argon2'
import { sendPasswordResetEmail } from './email'

const RESET_EXPIRY_MS = 60 * 60 * 1000 // 1 hour

export async function requestPasswordReset(email: string, webBaseUrl: string): Promise<void> {
  const [user] = await db.select().from(users).where(eq(users.email, email)).limit(1)
  if (!user) return // Don't reveal whether email exists

  const token = randomBytes(32).toString('hex')
  await db.insert(passwordResets).values({
    token,
    userId: user.id,
    expiresAt: new Date(Date.now() + RESET_EXPIRY_MS),
  })

  const resetUrl = `${webBaseUrl}/reset-password?token=${token}`
  await sendPasswordResetEmail({ to: user.email, resetUrl, userName: user.name })
}

export async function resetPassword(token: string, newPassword: string): Promise<void> {
  const [reset] = await db
    .select()
    .from(passwordResets)
    .where(and(
      eq(passwordResets.token, token),
      isNull(passwordResets.usedAt),
      gt(passwordResets.expiresAt, new Date()),
    ))
    .limit(1)

  if (!reset) throw new Error('INVALID_TOKEN')

  const passwordHash = await argonHash(newPassword)
  await db.update(users)
    .set({ passwordHash, mustChangePassword: false })
    .where(eq(users.id, reset.userId))
  await db.update(passwordResets)
    .set({ usedAt: new Date() })
    .where(eq(passwordResets.token, token))

  await db.delete(db.$with('sessions').as(db.select().from(/* invalidates all user sessions */)))
}

export async function changePassword(userId: string, newPassword: string): Promise<void> {
  const passwordHash = await argonHash(newPassword)
  await db.update(users)
    .set({ passwordHash, mustChangePassword: false })
    .where(eq(users.id, userId))
}
```

```ts
  app.get('/users', {
    preHandler: [requireAuth, requirePermission('usuarios', 'ver')],
  }, async () => {
    return db.select({
      id: users.id,
      email: users.email,
      name: users.name,
      status: users.status,
      mustChangePassword: users.mustChangePassword,
      createdAt: users.createdAt,
    }).from(users)

  app.post('/users', {
    preHandler: [requireAuth, requirePermission('usuarios', 'crear')],

    const user = await createUser(input)
    await emit({
      userId: req.user!.id,
      rolEjercido: req.user!.roles,
      action: 'USER_CREATED',
      resource: 'users',
      resourceId: user.id,
      result: 'ok',
      requestId: (req.headers['x-request-id'] as string) ?? crypto.randomUUID(),
      ip: req.ip,
      payload: { email: input.email, roles: input.roles },
    })
    reply.code(201)
    return user
  })

  app.patch('/users/:id', {
    preHandler: [requireAuth, requirePermission('usuarios', 'editar')],
  }, async (req) => {
    const id = (req.params as { id: string }).id
    const patch = updateUserSchema.parse(req.body)
    await updateUser(id, patch)
    await emit({
      userId: req.user!.id,
      rolEjercido: req.user!.roles,
      action: 'USER_UPDATED',
      resource: 'users',
      resourceId: id,
      result: 'ok',
      requestId: (req.headers['x-request-id'] as string) ?? crypto.randomUUID(),
      ip: req.ip,
      payload: patch,
    })
    return { ok: true }
  })

  app.post('/users/:id/roles', {
    preHandler: [requireAuth, requirePermission('usuarios', 'editar')],
  }, async (req) => {
    const id = (req.params as { id: string }).id
    const { roles: newRoles } = assignRolesSchema.parse(req.body)
    await setUserRoles(id, req.user!.id, newRoles)
    await emit({
      userId: req.user!.id,
      rolEjercido: req.user!.roles,
      action: 'USER_ROLES_CHANGED',
      resource: 'users',
      resourceId: id,
      result: 'ok',
      requestId: (req.headers['x-request-id'] as string) ?? crypto.randomUUID(),
```

```ts
import { and, eq, gte, lte, lt, sql } from 'drizzle-orm'
import { db } from '@/db/client'
import { auditLog } from '@/db/schema'

export interface AuditFilter {
  userId?: string
  action?: string
  resource?: string
  from?: Date
  to?: Date
  cursor?: number
  limit?: number
}

export async function queryAudit(filter: AuditFilter) {
  const where = and(
    filter.userId ? eq(auditLog.userId, filter.userId) : undefined,
    filter.action ? eq(auditLog.action, filter.action) : undefined,
    filter.resource ? eq(auditLog.resource, filter.resource) : undefined,
    filter.from ? gte(auditLog.createdAt, filter.from) : undefined,
    filter.to ? lte(auditLog.createdAt, filter.to) : undefined,
    filter.cursor ? lt(auditLog.id, filter.cursor) : undefined,
  )

  const rows = await db
    .select()
    .from(auditLog)
    .where(where)
    .orderBy(sql`${auditLog.id} DESC`)
    .limit(filter.limit ?? 50)

  return {
    rows,
    nextCursor: rows.length > 0 ? rows[rows.length - 1].id : null,
  }
}
```

```ts
import { cookies, headers } from 'next/headers'
import { ApiError } from './errors'

const API_URL = process.env.API_INTERNAL_URL!

export async function apiServerFetch<T>(
  path: string,
  init: RequestInit = {},
): Promise<T> {
  const cookieStore = await cookies()
  const headerStore = await headers()

  const res = await fetch(`${API_URL}${path}`, {
    ...init,
    headers: {
      ...init.headers,
      Cookie: cookieStore.toString(),
      'x-request-id': headerStore.get('x-request-id') ?? crypto.randomUUID(),
    },
    cache: init.cache ?? 'no-store',
  })

  if (!res.ok) {
    throw new ApiError(res.status, await res.text())
  }
  return res.json()
}

export async function getServerUser(): Promise<{ id: string; roles: string[] } | null> {
  try {
    return await apiServerFetch('/api/auth/me')
  } catch (e) {
    if (e instanceof ApiError && e.status === 401) return null
    throw e
  }
}
```

```ts
        sameSite: 'lax',
```

- [ ] **Step 1: Write `api/drizzle/seed.ts`**

```ts
import { drizzle } from 'drizzle-orm/postgres-js'
import postgres from 'postgres'
import { eq } from 'drizzle-orm'
import { hash as argonHash } from '@node-rs/argon2'
import * as schema from '../src/db/schema'

const { users, roles, userRoles } = schema

async function main() {
  if (process.env.NODE_ENV === 'production' && process.env.SEED_CONFIRM !== 'yes') {
    console.error('ERROR: refusing to seed in production without SEED_CONFIRM=yes')
    process.exit(1)
  }

  const db = drizzle(postgres(process.env.DATABASE_URL!), { schema })

  // Check if any admin already exists
  const existingAdmins = await db
    .select({ name: roles.name })
    .from(roles)
    .innerJoin(userRoles, eq(userRoles.roleName, roles.name))
    .where(eq(roles.name, 'admin'))
    .limit(1)

  if (existingAdmins.length > 0) {
    console.error('ERROR: admin already exists. Refusing to seed.')
    process.exit(1)
  }

  // Insert the 4 roles
  await db.insert(roles).values([
    { name: 'admin', description: 'Administrador del sistema' },
    { name: 'seller', description: 'Vendedor de ruta' },
    { name: 'pos', description: 'Punto de venta fijo' },
    { name: 'contador', description: 'Contador externo (read-only)' },
  ]).onConflictDoNothing()

  // Create the first admin
  const email = process.env.SEED_ADMIN_EMAIL ?? 'admin@aquazaku.com'
  const name = process.env.SEED_ADMIN_NAME ?? 'Admin Inicial'
  const password = process.env.SEED_ADMIN_PASSWORD

  if (!password) {
    console.error('ERROR: SEED_ADMIN_PASSWORD is required')
    process.exit(1)
  }

  const passwordHash = await argonHash(password)
  const [admin] = await db.insert(users).values({
    email, name, passwordHash,
  }).returning({ id: users.id })

  await db.insert(userRoles).values({ userId: admin.id, roleName: 'admin' })

  console.log(`✓ Seed complete. Admin: ${email}`)
  process.exit(0)
}

main().catch((e) => { console.error(e); process.exit(1) })
```
