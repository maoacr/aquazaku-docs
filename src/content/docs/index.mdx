## Cómo se usa esta documentación

Esta documentación se escribe **a medida que se construye**, no después.
Cada decisión técnica que se toma queda registrada como un ADR en
[Decisiones técnicas](/decisiones/) — con contexto, alternativas y consecuencias.

Si algo del sistema no está acá, no existe.
